# Hive Mono Pillar Logo Proposals

Ten focused iterations based on the selected Mono Pillar direction.

Each proposal includes:

- `.svg`: 1024x1024 vector master
- `.png`: 1024x1024 raster export for quick preview and app-icon tests
- `index.html`: local gallery for side-by-side comparison
- `contact-sheet.png`: large comparison sheet
- `contact-sheet-small.png`: 64px readability check

## Directions

- **Selected Pillar**: The selected direction preserved almost as-is: strict, premium, and small-size friendly.
- **Taller Pillar**: A more vertical silhouette with stronger app-icon presence and a smaller signal dot.
- **Squircle Pillar**: A calmer variant with a wider body and gentler corners.
- **Outline Pillar**: A lighter mark that keeps the same silhouette but feels more airy and frontend-friendly.
- **Cut Pillar**: A sharper, more architectural variant with a bottom notch instead of a floating dot.
- **Inverted Pillar**: A dark-mode first version with the same premium contrast but less beige warmth.
- **Pin Pillar**: A more product-like take: same H, but the body reads as a location/workspace pin.
- **Slab Pillar**: The most brutalist option: flatter corners, heavier geometry, and strong favicon readability.
- **Loop Pillar**: A softer identity variant where the H is still clear but the outer form feels more continuous.
- **Signal Pillar**: A subtle agent/status variant with one accent lane instead of the original dot.

## Practical Notes

These variants stay close to the selected black-and-cream pillar language. The main differences are outer silhouette, corner radius, accent treatment, and dark-mode behavior. The strongest candidate should remain recognizable at 64px before being promoted into the actual iOS, web, and Tauri icon sets.
